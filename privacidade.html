Política de Privacidade

Análise das Redes Sociais
Última atualização: 20/11/2026

1. Quem é responsável

O responsável por este painel é Gilson Caetano. Para qualquer assunto sobre privacidade, escreva para apcturvo@gmail.com.

2. O que é este serviço

O painel permite acompanhar métricas de Páginas do Facebook e de contas profissionais do Instagram que o próprio usuário autoriza, e reunir esses números em indicadores e relatórios para a organização dele.

3. Quais dados coletamos

  • Login: o e-mail informado para entrar. O acesso é feito por link enviado a esse e-mail, sem senha.
  • Organização: o nome que o usuário dá à organização e o papel de cada membro (proprietário, administrador, editor ou leitor).
  • Conexão com a Meta: o identificador e o nome das Páginas do Facebook e das contas do Instagram autorizadas, além do nome de usuário do Instagram. Os tokens de acesso são guardados cifrados.
  • Métricas: quando a sincronização estiver ativa, indicadores como alcance, impressões, engajamento, visitas ao perfil, seguidores, cliques e dados agregados de público (faixa etária, cidade e similares).

Não coletamos senhas de redes sociais, mensagens privadas nem dados pessoais de seguidores individualmente.

4. Permissões pedidas à Meta

Pedimos apenas permissões de leitura: pages_show_list, pages_read_engagement, instagram_basic e instagram_manage_insights. Não publicamos, não respondemos comentários e não alteramos nada em nome do usuário.

5. Como usamos os dados

Usamos os dados somente para mostrar os indicadores à organização que os autorizou e para gerar os relatórios dela. Não vendemos dados, não os usamos para publicidade de terceiros e não os compartilhamos com outras empresas.

6. Onde os dados ficam

Os dados ficam no banco de dados e no sistema de login do Supabase, e o painel é hospedado na Vercel. Esses serviços processam os dados em nome deste painel.

7. Por quanto tempo guardamos

Guardamos os dados enquanto a conta conectada estiver ativa e a organização existir. Quando o usuário pedir a exclusão, apagamos os dados conforme descrito na página de exclusão de dados.

8. Seus direitos

Você pode pedir acesso, correção ou exclusão dos seus dados a qualquer momento, escrevendo para apcturvo@gmail.com. Você também pode revogar o acesso do app a qualquer momento nas configurações do Facebook.

9. Alterações

Esta política pode ser atualizada. A data no topo mostra a última alteração.
